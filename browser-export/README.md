# 地区別売上＋食材理論値のExcel出力（v4）

会社のPCでログイン済みの分析帳票メインメニューから、年・月・店舗番号を1回指定して2帳票のExcel出力を操作するブックマークレットです。

| 帳票 | 店舗・期間 |
| --- | --- |
| B10 地区別売上 | 指定店舗・指定月・日付あわせ |
| B119 食材理論値（食材誤差を含む） | 同じ店舗・指定月の前月・月次 |

2026年10月なら地区別売上は10月、食材理論値は9月です。2026年1月なら食材理論値は2025年12月になります。

## 登録と使用方法

1. GitHubの「Code → Download ZIP」で取得し、ZIPを展開します。
2. `地区別売上_お気に入り登録.html` を会社PCのEdgeまたはChromeで開きます。
3. Ctrl＋Shift＋Bでお気に入りバーを表示し、青い「地区別＋食材を出力 v4」をバーへドラッグします。
4. 会社サイトの分析帳票メインメニューを開き、登録したお気に入りを押します。
5. 年・月・店舗番号を入力します。初期値は2026年10月・0589です。
6. メインメニューを閉じずに待ち、ブラウザーのダウンロード一覧で2ファイルを確認します。

店舗一覧は画面外もスクロールして検索します。以前の店舗絞込みで除外された店舗や、表示権限のない店舗は選べません。B10のブランドは現在の設定のままです。

## 動作と制限

- B10は別タブで開きます。先にExcel出力を操作し、結果画面を残して進行中のダウンロードが画面遷移で中断しないようにします。
- B119はメインメニュー内の枠に開きます。同一サイトの画面内表示が禁止されている場合は停止します。画面表示の制限を解除する処理はありません。
- B119は月次と前月を設定し、結果画面の帳票名・店舗番号・月初から月末までの期間を照合してからExcel出力を操作します。
- 出力ボタンの操作からダウンロード完了までは判定できません。ブラウザーに複数ファイルのダウンロード許可が出た場合は内容を確認し、保存結果はダウンロード一覧で確認してください。
- B10で失敗した場合はB119へ進みません。B119だけ失敗した場合は、地区別売上の出力は指示済みであることを明示します。
- Cookie・パスワードを読み取ったり、帳票データを外部送信したりする処理はありません。
- v3までのB10出力は利用者の会社PCで確認済みです。v4のB119連続出力はローカル検証済みですが、実際の社内サイトでは未検証です。

## 構成とビルド

- `export.js`: 既存B10の単体処理。
- `food-selection.js`: B119の店舗・前月・月次の設定。
- `combined-controller.js`: メインメニューからの連続処理とB119結果の照合。
- `build.py`: 上記を外部読み込み不要の `combined-export.js` と登録用HTMLへまとめます。

変更後は `python browser-export/build.py` を実行します。生成されたJSとHTMLも配布物としてコミットします。

## ローカル検証

Python、Playwright、Chromiumが必要です。会社サイトには接続せず、テスト用の画面・ファイルで確認します。

```sh
python browser-export/test_combined_export.py
python browser-export/test_food_selection.py
python browser-export/test_menu_start.py
python browser-export/test_store_search.py
```

連続処理では2ファイルの保存、年越し、最初のダウンロードが遅い場合、食材の店舗・月が違う場合の停止を確認します。個別テストでは仮想スクロール、店舗がない場合、別タブとページ全体の切り替えも確認します。
