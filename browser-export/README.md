# 地区別売上のExcel出力（試作）

会社のPCでログイン済みの分析帳票メインメニュー、またはB10検索画面から使うブックマークレットです。
年・月・店舗番号を指定し、一覧の画面外の行もスクロールして探して、日付あわせで実行し、結果画面の店舗と年月を照合してExcel出力をクリックします。
アカウント情報、Cookie、社内データを外部へ送信する処理はありません。サイト自身の出力ボタンを操作します。

## 使用方法

配布用HTMLを開き、青い「地区別売上を出力 v3」をブラウザーのお気に入りバーへドラッグします。
会社サイトの分析帳票メインメニューでお気に入りを押します。同一サイトのB10検索画面を別タブで自動的に開き、店舗一覧の読み込みを待って処理を続けます。メインメニューは処理完了まで閉じないでください。B10検索画面からの起動も引き続き利用できます。
年・月・店舗番号を入力します。初期値は2026年10月・0589です。
ダウンロード完了はブラウザーのダウンロード一覧で確認してください。

## 制限と検証範囲

- ブランドは結果画面の現在値のままです。添付された画面は「全て」です。
- 月途中は、サイトが返す最新日までの期間になります。
- 店舗一覧を最大45秒自動スクロールして探します。店舗番号の先頭ゼロや行IDの違いにも対応します。
- 店舗絞込みダイアログの自動操作は含みません。以前の絞込みで除外された店舗や権限のない店舗は選べません。
- 同じページ内の遷移、参照可能な同一オリジンの別窓を待機します。
- メインメニューから起動した場合は、親画面から同一サイトの別タブを監視するため、別タブのページ全体が切り替わっても処理を続けられます。B10から直接起動した場合のページ全体の切り替えでは実行が中断するため、結果画面で3分以内に同じお気に入りをもう一度押すと再開します。
- ブラウザーや会社の制限でブックマークレット・別窓・ダウンロードが禁止されている場合は動作しません。制限を解除・回避する処理はありません。
- 添付DOMを使ったローカルの画面遷移テストを実施。v2の店舗自動検索とExcel保存は利用者の会社PCで確認済みです。v3のメインメニューからの起動は社内サイトで未検証です。
- ワンクリックでの全工程完了を保証する完成版ではありません。会社PCでの試行結果を元に調整が必要です。

`export.js` が可読な実装です。配布HTMLには同じコードをブックマークURLとして埋め込みます。

## ローカル検証

Python、Playwright、Chromiumのある環境で `python browser-export/test_store_search.py` を実行します。テスト用の店舗一覧と帳票画面のみを使い、社内サイトには接続しません。画面外の店舗、最下部からの検索、先頭ゼロと行ID、存在しない店舗、結果店舗の不一致を確認します。

`python browser-export/test_menu_start.py` で、メインメニューからの起動、別タブ内のSPA遷移、ページ全体の遷移、店舗一覧の読み込み待ち、模擬Excelのダウンロード、ポップアップを開けない場合の停止を確認します。
